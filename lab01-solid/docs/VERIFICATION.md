## Границы, рассмотренные при ревью

- Данные находятся в памяти; сохранение, многопоточность и дополнительная инфраструктура не входят в выбранное решение. При необходимости сохранить данные после закрытия потребуется отдельное расширение.
- Запрет смены типа при редактировании выполняет `CatalogService`. Репозиторий сам не дублирует бизнес-правило; консоль изменяет каталог через сервис. Обход сервиса в будущем потребует соблюдать это правило отдельно.
- Формы и подробный вывод используют `switch` для трёх известных видов. OCP демонстрируется расширением критериев поиска, а не обещанием не менять формы при добавлении четвёртого вида.
- Уникальность Id гарантируется для текущего каталога; `NextId` также учитывает номера, уже выданные этим экземпляром сервиса. Вечное резервирование исторических номеров и сохранение счётчика между запусками не требуется. После удаления первоначальной записи до первой выдачи нового номера её номер может быть использован снова.
- Поиск названия учитывает издание и произведения альманаха. Названия газетных колонок в поиск названий не включены; журналисты участвуют в поиске авторов.
- Документация и launchers проверены основным исполнителем отдельно от ревью исходников.

Лабораторная реализована локально. Git/GitHub и тег lab-01 не создавались. Понимание кода пользователем и пробная защита не объявляются выполненными автоматически.
