# Лабораторная №1 — каталог библиотеки

Задание 2: консольная программа на C# с применением пяти принципов SOLID.

Меню, подсказки, названия типов и сообщения об ошибках — на английском. Учебные материалы ниже — на русском. Названия и авторы изданий являются данными и могут содержать кириллицу.

## Запуск

На этой машине установлен подходящий .NET SDK 8.0.100. Приложение рассчитано на .NET 8; сторонних пакетов нет, соединение с БД не требуется. `global.json` выбирает SDK 8, `NuGet.Config` отключает внешние источники пакетов, которые этому решению не нужны.

Из PowerShell:

```powershell
Set-Location D:\RPGgame\labs\lab01-solid
.\run.cmd
```

Или открой `run.cmd` в папке лабораторной. В Visual Studio можно открыть [LibraryCatalog.sln](LibraryCatalog.sln) и выбрать `LibraryCatalog.Console` запускаемым проектом.

Прямая команда из папки лабораторной:

```powershell
dotnet run --project src/LibraryCatalog.Console -c Release
```

Команды выполняются из папки лабораторной: так используется её `global.json`. В `Program.cs` устанавливается UTF-8 для украинских и русских названий.

## Что умеет программа

| Пункт | Действие |
|---|---|
| 1 | Показать весь каталог со всеми полями |
| 2 | Показать каталог группами по типу издания |
| 3 | Добавить книгу, газету или альманах с ручным вводом |
| 4 | `Generate a random publication`: фабрика создаёт готовое случайное издание без ввода полей |
| 5 | Редактировать издание по ID |
| 6 | Удалить издание по ID |
| 7 | Найти по названию, издательству, году или автору |
| 0 | Завершить работу |

При запуске загружаются четыре учебные записи: две книги, газета с двумя колонками и альманах с двумя произведениями. Примеры придуманы для лабораторной, но выглядят как обычный каталог: книга `The Lantern Keeper` автора Oliver, издательство `Silverleaf Press`, жанр `Mystery`. И начальный каталог, и фабрика используют правдоподобные названия вместо буквенных заглушек.

**Каталог хранится в памяти.** После закрытия изменения исчезают; следующий запуск снова загружает примеры. Файловое сохранение не входит в выбранное задание.

## Правила работы

- ID назначается автоматически, при редактировании сохраняется. Тип издания при редактировании не меняется.
- Строковые поля обязательны. Номер газеты и число страниц положительны. Год — от 1 до 9999.
- Дата вводится как `ДД.ММ.ГГГГ`, например `26.10.2026`; несуществующая дата отклоняется.
- При редактировании Enter оставляет прежнее значение поля. Список колонок или произведений можно оставить или заменить полностью.
- Поиск текста работает по части строки без учёта регистра. Поиск года — по точному числу.
- Поиск названия включает названия произведений альманаха. Поиск автора учитывает автора книги, авторов произведений и журналистов газетных колонок.
- У газеты дополнительно задано издательство/редакция для общего поиска. Год газеты определяется датой выпуска.
- Колонки и произведения — части соответствующего издания, а не дополнительные записи верхнего уровня.
- Ошибочный ввод запрашивается повторно. Отсутствующий ID выводит сообщение. EOF закрывает приложение; незавершённая операция не меняет каталог.

## Быстрая демонстрация

1. Введи `1`: просмотри все типы и их поля.
2. Введи `2`: увидишь группы `Book`, `Newspaper`, `Almanac`.
3. Введи `7`, затем `4`, затем `Scarlett`: найдутся газета и альманах.
4. Введи `7`, затем `1`, затем `A Quiet Morning`: найдётся альманах по названию вложенного произведения.
5. Введи `3`, затем `1` и заполни книгу: её ID будет `5`.
6. Введи `5`, затем `5`: измени название, остальные поля оставь через Enter.
7. Введи `4`: фабрика выберет случайный тип, заполнит поля и добавит издание с новым ID. Повторяй пункт 4 для новых объектов.
8. Введи `6`, затем `5`: удали добавленную вручную книгу.
9. Введи `0`: заверши работу.

## Сборка и проверки

```powershell
dotnet build LibraryCatalog.sln -c Release
.\test.cmd
```

Проверки — самостоятельное консольное приложение с ненулевым кодом выхода при ошибке. Они не требуют xUnit и пакетов из интернета. Поэтому используется `test.cmd` или `dotnet run --project tests/LibraryCatalog.Tests -c Release`, а не `dotnet test`.

Проверяются правила моделей, общие договоры всех типов, CRUD, поиск, независимость вложенных коллекций, генерация фабрикой, английский интерфейс и консольные сессии, включая неверный ввод и EOF посреди изменения.

## Фабрика случайных изданий

`RandomPublicationFactory` реализует `IRandomPublicationFactory`. Метод `Create(id)` сам выбирает `Book`, `Newspaper` или `Almanac` и заполняет поля из английских наборов данных. Случайны также издательство, авторы, год, число страниц, дата газеты и состав вложенных списков. Создаются корректные календарные даты.

Меню получает фабрику через конструктор и вызывает её в пункте 4. Поэтому пользователь не вводит поля, а меню не содержит конструкторов случайных книг, газет и альманахов. Выдачей ID и сохранением по-прежнему занимается каталог.

Это **простая фабрика (Simple Factory)**, а не иерархия создателей GoF Factory Method. Ручное добавление в пункте 3 сохранено как отдельное требование методички.

  CoreTests.cs          проверки ядра
  ConsoleTests.cs       пользовательские сценарии
