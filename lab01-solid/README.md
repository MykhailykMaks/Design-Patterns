# Лабораторна робота №1 — каталог бібліотеки

**Завдання 2:** консольна програма мовою C#, що демонструє п’ять принципів SOLID.

Каталог містить книги, газети й альманахи. Меню, підказки та повідомлення програми написані англійською; документація — українською.

## Запуск

Потрібен **.NET 8 SDK**. Із кореня репозиторію перейдіть до папки лабораторної:

```powershell
cd lab01-solid
.\run.cmd
```

Також можна відкрити `run.cmd` у папці лабораторної. У Visual Studio відкрийте [LibraryCatalog.sln](LibraryCatalog.sln) і виберіть `LibraryCatalog.Console` як проєкт запуску.

Для запуску через .NET CLI виконайте з папки `lab01-solid`:

```shell
dotnet run --project src/LibraryCatalog.Console -c Release
```

`global.json` задає вибір SDK 8. Програма не використовує сторонніх NuGet-пакетів; `NuGet.Config` вимикає непотрібні зовнішні джерела пакетів. Для консольного введення й виведення використовується UTF-8.

## Можливості

| Пункт меню | Дія |
|---|---|
| 1 | Показати всі видання з усіма полями |
| 2 | Згрупувати видання за типом |
| 3 | Вручну додати книгу, газету або альманах |
| 4 | Створити й додати випадкове видання через фабрику |
| 5 | Редагувати видання за ID |
| 6 | Видалити видання за ID |
| 7 | Знайти видання за назвою, видавництвом, роком або автором |
| 0 | Завершити роботу |

Під час запуску створюються чотири навчальні записи: дві книги, газета з колонками та альманах із творами різних авторів. Приклади вигадані, але мають правдоподібні дані: книга `The Lantern Keeper` автора Oliver, видавництво `Silverleaf Press`, жанр `Mystery`.

**Каталог зберігається в оперативній пам’яті.** Після закриття програми зміни зникають; наступний запуск знову завантажує початкові приклади.

## Дані видань

- **Книга:** назва, автор, жанр, рік видання, видавництво, кількість сторінок.
- **Газета:** назва, номер, дата випуску, видавництво або редакція, колонки та їхні журналісти. Рік визначається датою випуску.
- **Альманах:** назва, жанр, рік, видавництво, кількість сторінок і перелік творів із назвами та авторами.

Кожне видання має власний ID. Колонки й твори є частинами відповідного видання, а не окремими записами верхнього рівня каталогу.

## Правила роботи

- ID призначається автоматично та зберігається під час редагування. Змінити тип видання редагуванням не можна.
- Обов’язкові текстові поля не можуть бути порожніми. Номер газети й кількість сторінок мають бути додатними; рік — від 1 до 9999.
- Дата вводиться у форматі `DD.MM.YYYY`, наприклад `26.10.2026`. Неіснуюча календарна дата відхиляється.
- Під час редагування Enter залишає поточне значення поля. Список колонок або творів можна зберегти чи замінити повністю; вибір підтверджується через `y/n`.
- Текстовий пошук працює за частиною рядка без урахування регістру; рік порівнюється точно.
- Пошук за назвою враховує назву видання та назви творів альманаху. Пошук за автором враховує автора книги, авторів творів і журналістів газетних колонок.
- Некоректне введення запитується повторно. Якщо ID не знайдено, програма показує повідомлення. Кінець потоку введення завершує програму; незавершена операція не змінює каталог.

## Приклад використання

1. Введіть `1`, щоб переглянути початкові видання та їхні поля.
2. Введіть `2`, щоб побачити групи `Book`, `Newspaper`, `Almanac`.
3. Введіть `7`, потім `4`, потім `Scarlett`: знайдуться газета й альманах.
4. Введіть `7`, потім `1`, потім `A Quiet Morning`: знайдеться альманах за назвою вкладеного твору.
5. Введіть `3`, потім `1` і заповніть дані книги. У новій сесії після початкових записів вона отримає ID `5`.
6. Введіть `5`, потім `5`, щоб відредагувати цю книгу. Enter залишає значення поля без змін.
7. Введіть `4`, щоб фабрика створила випадкове видання з готовими даними.
8. Введіть `6`, потім `5`, щоб видалити додану вручну книгу.
9. Введіть `0`, щоб завершити роботу.

## Фабрика випадкових видань

`RandomPublicationFactory` реалізує `IRandomPublicationFactory`. Метод `Create(id)` вибирає випадковий тип — `Book`, `Newspaper` або `Almanac` — і створює об’єкт із заповненими полями.

Із підготовлених наборів вибираються назви, автори, видавництва та жанри. У допустимих діапазонах генеруються роки, кількість сторінок, номери й дати газет; також формуються списки колонок або творів.

У пункті `4 - Generate a random publication` вводити поля не потрібно. Меню отримує фабрику через конструктор, а видачею ID і додаванням до каталогу займається `CatalogService`.

Це **проста фабрика (Simple Factory)**. Ручне додавання в пункті 3 також доступне відповідно до умов завдання.

## Збірка та перевірки

Із папки `lab01-solid`:

```shell
dotnet build LibraryCatalog.sln -c Release
dotnet run --project tests/LibraryCatalog.Tests -c Release
```

У Windows перевірки також запускаються командою `.\test.cmd`.

Тестовий проєкт — окрема консольна програма: вона показує результат кожної перевірки та повертає ненульовий код завершення, якщо є помилка. Для цього набору використовується `dotnet run`, а не `dotnet test`.

Перевіряються моделі, операції каталогу, пошук, незалежність вкладених колекцій, фабрика, англійський інтерфейс і консольні сценарії, зокрема помилкове введення та переривання редагування.

## Структура

```text
src/LibraryCatalog.Core/
  Models/     моделі видань і правила коректності даних
  Catalog/    інтерфейси сховища, сховище в пам’яті та сервіс операцій
  Search/     критерії та сервіс пошуку
  Factories/  інтерфейс і реалізація фабрики випадкових видань
  Samples/    початкові навчальні записи
src/LibraryCatalog.Console/
  Program.cs            створення та з’єднання компонентів
  ConsoleMenu.cs        обробка команд меню
  ConsoleInput.cs       читання та перевірка введення
  PublicationInput.cs   введення полів і створення моделей
  ConsoleCatalogView.cs виведення результатів
tests/LibraryCatalog.Tests/
  CoreTests.cs          перевірки ядра
  FactoryTests.cs       перевірки фабрики
  ConsoleTests.cs       користувацькі сценарії
```
